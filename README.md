VI Trophy Atlas is an offline guide and tracker for the 55 PS5 trophies of Grand Theft Auto VI. It shows each trophy's
official name, description and grade, and saves your checklist in the browser with export and import. You get kind
filters, a spoiler setting for story and hidden trophies, a 7-stage platinum roadmap and a missables view. Every trophy
has its own guide, written for this app, with counters and linked sources (KeenGamer, GTABase, Fextralife, Output Lag).
This is an unofficial fan project: no Rockstar logo or artwork is used.

## Run it

```sh
node serve.ts            # then open http://localhost:8080
node tests/check-data.mjs  # checks the data against the official list
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
